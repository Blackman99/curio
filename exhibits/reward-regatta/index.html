What is this?

In 2016 OpenAI trained an agent on the boat-racing game CoastRunners, rewarding it with the game's score. Score came from hitting targets along the course, so the agent found a lagoon where targets kept respawning and circled it forever, crashing and catching fire, never finishing, and still outscoring human players by about 20% (Jack Clark & Dario Amodei, Faulty Reward Functions in the Wild). This is a small, honest copy of that.

The lake is a grid of 195 water cells; the boat moves one cell per move, in any of 8 directions, and can't cut a corner of land. Touching a buoy that is up pays its points and knocks it down; it comes back up once the boat has touched both of the others. Crossing the finish line pays the prize and ends the race. So the state the boat sees is its cell plus which buoys are down, in order: 1,950 states.

Learning is tabular Q-learning (Watkins, 1989), computed here in your browser: Q(s,a) ← Q(s,a) + α·(r + γ·max Q(s′,·) − Q(s,a)), with α = 1 (the lake is deterministic: the same move from the same spot always lands in the same place), ε = 0.3 random moves, and each practice run starting from a random cell with a random set of buoys down, for at most 60 moves. A run cut off at 60 moves still looks ahead with γ; only crossing the line ends one. The race you watch is the greedy plan: from each spot, the move with the highest Q (when several moves tie, the one nearest its current heading). Arrows on the water show that plan for the buoys currently up, pointing between moves that tie, darker where it expects to earn more.

Progress points pay for every move that brings the boat closer to the line (by sailing distance). That is the trap Randløv & Alstrøm (1998) fell into with a learning bicycle that rode in circles around its goal. Charging it back makes it potential-based shaping, F = γ·Φ(s′) − Φ(s) with Φ = −points × distance, which Ng, Harada & Russell (1999) proved cannot change which plan is best.

Real: the lake, the rules, every Q-learning update (double precision, a seeded generator, so a run replays exactly). Checked offline against an exact solution of each rule set (value iteration): over 108 rule sets × 3 seeds, the learned race matched the best possible kind of race (loop, finish, finish with buoys, or stopping short) in 322 of 324 runs. Not real: a boat. Moves are grid steps, not sailing; wind, speed and collisions don't exist.

The lesson isn't that Q-learning is clever or broken. It does exactly what the numbers say. Victoria Krakovna keeps a public list of specification gaming like this, found in real systems.
