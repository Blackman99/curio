What is this?

Deep Zoom is a treasure dive past 10⁻¹⁰⁰ into the Mandelbrot set. Every frame is computed live in your browser using Mandelbrot perturbation theory (K. I. Martin, 2013) paired with Zhuoran rebasing (2021) and a custom 32-bit Floatexp representation inside a WebGL2 fragment shader.

Why direct GPU floats hit a wall at 10⁻⁷

Standard GPUs iterate z ← z² + c in IEEE 754 single-precision float32, which carries only 24 bits of mantissa (about 7.2 decimal digits). Near c ≈ −0.185 + 1.014i, the spacing between adjacent float32 numbers is 2⁻²⁶ ≈ 1.49 × 10⁻⁸ horizontally and 2⁻²³ ≈ 1.19 × 10⁻⁷ vertically. How perturbation + Floatexp reaches 10⁻¹⁰⁹ at 60 fps

Instead of running slow arbitrary-precision arithmetic on every pixel, the page computes one reference orbit Zₙ₊₁ = Zₙ² + C in JavaScript using 512-bit fixed-point BigInt arithmetic (median 1.2 ms for the 10⁻¹⁰⁹ reference orbit) and uploads it into an RGBA32F texture. Every pixel only tracks its tiny deviation zₙ = Wₙ − Zₙ using Martin’s perturbation recurrence:

zₙ₊₁ = 2 Zₙ zₙ + zₙ² + Δc

Two obstacles remain on a float32 GPU. First, IEEE float32 underflows to zero at 2⁻¹²⁶ ≈ 1.18 × 10⁻³⁸, long before 10⁻¹⁰⁰; the shader therefore stores each complex number as a normalized vec2 mantissa plus a 32-bit signed integer exponent (Floatexp), using exact floatBitsToUint / uintBitsToFloat exponent shifts with zero rounding error. Second, when a pixel’s true orbit Wₙ = Zₙ + zₙ passes close to 0 while the reference does not, subtraction glitches appear; following Zhuoran (2021), whenever |Wₙ| < |zₙ| (or the reference escapes), the pixel resets zₙ ← Wₙ and rewinds the reference index to 0 (mean 1.7 rebases per pixel).

Verified against 512-bit direct iteration

Across 300 stratified pixels sampled at the target depths of all three dives (10⁻¹⁰⁹ period-120, 10⁻⁵³ period-185, and 10⁻¹⁶ period-22), 32-bit Floatexp perturbation matches independent 512-bit arbitrary-precision direct iteration to the exact escape step on 296/300 pixels and within ±1 step on 299/300 (the rare 1–3 step differences occur on chaotic boundary filaments where 24-bit perturbation rounding shifts escape by a step).
