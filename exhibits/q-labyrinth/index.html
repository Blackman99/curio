CURIO NO. 059 · Q LABYRINTH

What is this?

Q Labyrinth is a 4-shade handheld puzzle game where you are the maze architect and a tiny mouse learns your labyrinth from scratch using real tabular Q-learning (Watkins, 1989; Watkins & Dayan, 1992). Your goal is the opposite of a normal maze game: paint walls, cats, and cheese to make the mouse take as many episodes as possible to master a still-solvable maze.

The algorithm (real float64 math)

The grid has 13 × 9 = 117 cells and 4 actions (up, right, down, left). Starting from Q(s, a) = 0 everywhere, the mouse chooses a random action with probability ε and otherwise picks uniformly among the highest-valued actions in its current cell. After every step, it updates one table entry:

Q(s, a) ← Q(s, a) + α [ r + γ maxa′ Q(s′, a′) − Q(s, a) ]

Cheese ends an episode with +10; a cat ends it with −10; walls bounce the mouse back in place; episodes cap at 200 steps (α = 0.40). A maze counts as mastered on the first episode whose greedy policy walks cleanly from Start to Cheese with backed-up value at least 0.05 on every tile along the way (0.01 when step cost is on). The floor heatmap shades each tile by V(s) = maxa Q(s, a), and dark edge bars mark directions where a cat taught a negative Q-value. Switching to Q-4 splits each tile into all four action triangles.

What we measured across 30 seeds

All four built-in stages were benchmarked over 30 deterministic seeds (ε = 0.20, γ = 0.92, cap 1,500 episodes) and verified bit-for-bit against an independent Python/NumPy reference. The same engine also solves exact Bellman value iteration V*(s); after 2,500 episodes on Cat Alley (ε = 0.30, α = 0.20), the mouse’s learned values along the optimal path match V* to max error 0.0000.

Four surprises built into the game

  • Architecture beats raw length. Gauntlet is only 20 steps long — 8 steps shorter than Spiral (28) — yet takes median 1127 episodes vs 463 (with 198 cat hits). A decoy room plus a one-tile cat-guarded bridge turns random exploration into a minefield.
  • The hidden optimism of step cost. Flip the STEP switch from 0 to −0.04. Punishing every step sounds harsher, yet it makes Q-learning solve Keyhole 5.4× faster (50 vs 271 ep) and Gauntlet 10.2× faster (110 vs 1127 ep). Because Q starts at 0, any visited floor drops below 0, so unvisited tiles look strictly better — turning greedy steps into optimistic exploration (Sutton & Barto §2.6).
  • The ε cat paradox. On Cat Alley, raising ε from 0.05 to 0.50 slows mastery by 4.0× (63 → 254.5 ep; cat hits 25 → 211.5) because random exploration steps off the bridge before credit can crawl back.
  • The γ discount horizon. On Spiral, lowering γ from 0.92 (V*(S) = 1.05) to 0.75 shrinks the discounted cheese reward at Start to 0.004, below the 0.05 threshold — 30/30 seeds fail to master within 1,500 episodes.

What is computed vs visual

Computed live: every Q-table update, ε-greedy tie-break, BFS shortest path, Bellman value iteration V*(s), mastery check, and the 15-seed fair score (SCORE, Gauntlet par 1011 ep). Visual / audio craft: the 16×16 pixel sprites, Bayer 4×4 ordered dithering, LCD dot-matrix grid, and optional Web Audio square-wave bleeps.
